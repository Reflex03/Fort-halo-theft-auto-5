All of it in one file, $sources_zip, published with every release:

    - on Melty, as this mashup's optional "Source code" download (same release, not installed by Play);
    - and on GitHub when the release is tagged there: $repo/releases/download/v$version/$sources_zip

It holds every upstream file listed below (folder upstream/, checked against the hashes given here), the source
of this repository at the commit this release was built from (folder crafttheft/), and a SHA256SUMS file.
If that link ever stops working, open an issue at $repo/issues and we will send you the source.


1. bin/cthextract.exe: our game-content extractor  [GPL-3.0-only]
--------------------------------------------------------------------
Source: $repo
        commit $commit (release tag v$version), folder extractor/
It includes the vendored libraries in extractor/vendor/ (Reclaimer, CUE4Parse, Fmod5Sharp, MeshDecimator,
gta-toolkit, the ooz and vgmstream ports) with their patches. Build: extractor/build.sh (the .NET $runtime runtime
is compiled in: dotnet publish -c Release -r win-x64 --self-contained -p:PublishSingleFile=true).
